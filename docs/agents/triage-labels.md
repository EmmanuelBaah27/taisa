# Triage labels

| Matt role | Linear label |
| --- | --- |
| `needs-triage` | `needs-triage` |
| `needs-info` | `needs-info` |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `wontfix` | `wontfix` |

These labels classify incoming work only.

`ready-for-agent` means the issue is sufficiently clear for the next permitted workflow action. It does not approve Scope, Plan, Build, QA, or Ship.
