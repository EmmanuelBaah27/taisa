# Taisa Reusable Learnings

This append-only log retains evidence-backed findings likely to influence another
feature, agent, or future decision. It is not a session diary or project-status tracker.

Use one of these stable areas: `Product`, `Platform`, `Mobile`, `Backend`,
`Design System`, `AI`, `QA`, or `Workflow`.

Include root-cause findings, repeated QA evidence, reusable implementation patterns,
platform constraints discovered in practice, and non-obvious toolchain limitations.
Exclude routine activity, temporary debugging notes, unsupported preferences, and
feature-specific status that belongs in a scope, plan, QA note, pull request, or commit.

The `Promoted to` field links the canonical rule, decision, test, or domain-document
update created from a learning. A learning remains advisory until promoted. If new
evidence invalidates an entry, append a correcting row that cites the earlier entry;
never silently rewrite the evidence trail.
